# Customer Churn Analysis

## Project Overview
This project focuses on data quality assessment, data cleaning, and exploratory data analysis of a synthetic customer churn dataset.

## Objectives
- Identify missing values and duplicate records.
- Validate data types and numerical values.
- Perform data cleaning and validation.
- Analyze customer churn patterns.
- Generate meaningful visualizations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
The dataset contains 15 synthetic customer records and 11 columns.

## Data Quality Results
- Missing values: 0
- Duplicate rows: 0
- Duplicate customer IDs: 0
- IQR outliers: 0
- Total charges consistency: 15/15 records passed.

## Key Findings
- 8 customers were retained.
- 7 customers churned.
- All 7 month-to-month customers in this sample churned.
- Churned customers had a higher average support-ticket count.

## Conclusion
The exploratory analysis identified associations between contract type, support-ticket volume, and customer churn.

The results are illustrative because the dataset is small and synthetic. Further analysis using a larger dataset is recommended.
